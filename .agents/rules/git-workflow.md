# Repository Synchronization & Auto-Commit Protocol

Always observe the following rules when working in this project:

1. **Target Repository**:
   - Remote: `origin` (`https://github.com/BornilMahmud/devfestVC026.git`)
   - Branch: `main`
   - Committer: `Bornil Mahmud <bornilprof@gmail.com>`

2. **Auto-Commit Trigger**:
   - Whenever any file is added, edited, or deleted, or at the conclusion of every tool-use turn / feature implementation, commit and push changes.

3. **Execution Steps**:
   - `git add .`
   - `git commit -m "<concise descriptive message>"`
   - `git push origin main`
   - Confirm status with `git status`
